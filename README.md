# vCard QR Scanner Web App

This is a client-side JavaScript web application designed for mobile browsers. It scans QR codes using the phone camera, parses vCard data, and submits the extracted information to a public Google Form. No backend is required.

## Features
- Scan QR codes with phone camera
- Parse vCard data (Name, Email, Company, Position)
- Submit data to Google Form
- Mobile-friendly, simple UI

## Getting Started
1. Open the app link in your phone browser.
2. Allow camera access when prompted.
3. Scan a QR code containing vCard data.
4. Review the extracted information.
5. Submit to the Google Form.

## Deployment
- Host the app as a static website (GitHub Pages, Netlify, Vercel, Google Sites, etc.).
- Share the link via QR code, SMS, or email.
- No installation required; just open the link.

## Libraries Used
- [html5-qrcode](https://github.com/mebjas/html5-qrcode) for QR code scanning
- [vcard-parser](https://www.npmjs.com/package/vcard-parser) for vCard parsing

## For Non-Technical Users
- Simply open the provided link in your phone browser.
- Follow on-screen instructions.
- No app installation or account required.

## Customization
- Update the Google Form URL in the code to match your form.
- Style the app as needed for your organization.
